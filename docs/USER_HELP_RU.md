# Family Tree — Help для пользователя

## 1. Регистрация и вход
1. Откройте страницу входа.
2. Введите логин/пароль.
3. Подтвердите 2FA-код (если включено).
4. При необходимости отметьте «доверенное устройство».

## 2. Создание дерева
1. Создайте новое дерево (через интерфейс администратора/приложения).
2. Назовите дерево (например, «Род Ивановых»).
3. Добавьте первую персону — себя.

## 3. Добавление родственников
1. Перейдите в раздел «Люди».
2. Нажмите «+ Человек».
3. Заполните ФИО, даты, биографию, приватность.
4. Сохраните карточку.

## 4. Создание связей
1. Откройте «Связи».
2. Нажмите «+ Добавить связь».
3. Выберите «от кого», «к кому» и тип связи.
4. Сохраните.

## 5. Предложенные правки
1. Если вы не владелец дерева, создавайте предложенные правки.
2. Владелец дерева может:
   - одобрить правку;
   - отклонить правку.
3. После одобрения изменения применяются к карточке.

## 6. Медиа и безопасность
- Загружайте фото/документы в карточку человека.
- Большие и подозрительные файлы могут быть отклонены проверками.

## 7. Экспорт/импорт GEDCOM
- Администратор/оператор может экспортировать дерево в GEDCOM.
- Импорт GEDCOM добавит персон и базовые родительские связи.

## 8. Роли в дереве
- **Owner** — полный контроль.
- **Editor** — редактирование данных.
- **Viewer** — только просмотр.

## 9. Проблемы со входом
- Неверный пароль → проверьте раскладку/регистр.
- Неверный 2FA код → запросите новый или проверьте время на устройстве.
- Ошибка trusted device → войдите через обычный 2FA.
